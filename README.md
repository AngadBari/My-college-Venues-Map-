<h3><b>St. John College Venue Maps(Palgher)</b></h3>
<br>
This is a simple project that provides Google Map links for various venues at St. John College (Palghar). Built using HTML, Tailwind CSS, and JavaScript, this project helps students and visitors quickly access map locations for different buildings and facilities.

<h3><b>Features</b></h3><br>

🗺️ Google Map links for multiple venues.

🎨 Responsive design with Tailwind CSS.

⚡ Simple and lightweight interface.

🔗 Clickable buttons for easy navigation.

<h3><b>Technologies Used</b></h3>
<br>
<b>HTML</b> - Structure of the webpage.<br>
<br>
<b>Tailwind CSS</b> - Styling and responsive design.<br>
<br>
<b>JavaScript</b> - Dynamic interactions and Google Maps integration.
